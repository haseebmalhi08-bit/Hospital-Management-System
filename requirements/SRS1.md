#Functional Requirements
ID	Requirement
FR-1	The system shall register a new patient with a unique patient ID.
FR-2	The system shall assign a doctor to a registered patient.
FR-3	The system shall allow patient admission only if the patient is registered.
FR-4	The system shall allow treatment updates for admitted patients only.
FR-5	The system shall display the current patient status.
FR-6	The system shall allow patient discharge only if the patient is admitted.
FR-7	The system shall prevent any operation on unregistered patients.
FR-8	The system shall maintain correct patient status transitions throughout the system.
   
   #Non-Functional Requirements
ID	Requirement
NFR-1	The system shall maintain data consistency during all hospital operations.
NFR-2	The system shall ensure correctness using formal verification techniques.
NFR-3	The system shall provide reliable and consistent state transitions.
NFR-4	The system shall support validation through automated CI pipelines.
NFR-5	The system shall generate security validation reports using OWASP tools.
